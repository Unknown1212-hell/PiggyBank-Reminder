# 🐷 Piggybank Reminder

A simple web app that reminds you daily to save money in your piggybank with a progressive savings plan.

## Features

✅ **Daily Savings Sequence**: Start with $10 on Day 1, $11 on Day 2, and increase by $1 each day up to Day 21 (max $30)  
✅ **In-App Notifications**: Get daily reminders right in the app  
✅ **Progress Tracking**: Visual progress bar showing your completion status  
✅ **Total Savings Display**: See how much you've saved toward your $315 goal  
✅ **Browser Notifications**: Optional push notifications for daily reminders  
✅ **Mobile Friendly**: Works perfectly on phones, tablets, and desktops  
✅ **No Backend Needed**: All data stored locally in your browser  

## How It Works

1. **Day 1**: Save $10
2. **Day 2**: Save $11
3. **Day 3**: Save $12
4. ...
5. **Day 21**: Save $30

**Total Goal**: $315 (10+11+12+...+30)

## How to Use

1. Open `index.html` in your web browser
2. Click **"Saved Today"** after you've made your daily deposit
3. The app moves to the next day automatically
4. Watch your progress grow toward the $315 goal
5. Use **"Reset Progress"** if you need to start over

## Installation

No installation needed! Just open the files in any web browser.

### Local Setup
```bash
git clone https://github.com/Unknown1212-hell/PiggyBank-Reminder.git
cd PiggyBank-Reminder
# Open index.html in your browser
```

### Deploy (Free Options)

**GitHub Pages**:
1. Go to Settings → Pages
2. Set source to "main" branch
3. Your app will be live at: `https://Unknown1212-hell.github.io/PiggyBank-Reminder`

**Netlify**:
1. Drag and drop the folder to https://netlify.com
2. Your app will be live instantly
